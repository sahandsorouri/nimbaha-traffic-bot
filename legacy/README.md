# Legacy — nimbaha Telegram bot

This is the original project: a Telegram bot that reported internet data-usage
for the "nimbaha" ISP site (`/check`, `/subscribe`, daily report, data-saving
tips). The scheduler was disabled when the nimbaha site went internal.

It is unrelated to the current **Claude Usage Bar** menu bar app and is kept here
only for reference. Nothing in this folder is imported by the menu bar app.

Files: `bot.py`, `scraper.py`, `database.py`, `auth.py`, `debug_scraper.py`,
`Dockerfile`, `docker-compose.yml`, `requirements.txt`, `SETUP.md`.
